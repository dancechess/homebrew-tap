# DanceChess tap

Homebrew formulae and casks for [DanceChess](https://dancechess.com).

```sh
brew tap dancechess/tap
brew install --cask dc-studio
```

- **dc-studio** — a native Mac chess database. [Source](https://github.com/dancechess/studio)

These live here rather than in `homebrew/cask` because that repository asks a
self-submitted project for 90 forks, 90 watchers or 225 stars first.
